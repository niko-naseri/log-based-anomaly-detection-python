# Reproducibility and environment

## Verified local execution

- Python **3.13.5**
- scikit-learn **1.8.0**
- pandas **2.2.3**
- NumPy **2.3.5**
- matplotlib **3.10.8**
- pytest **9.0.2**
- 423 sanitized synthetic auth events; 48 windows; 5 labeled injected bursts.
- `python -m pytest` passed **10 automated tests** during package creation.

## Setup

```bash
python -m venv .venv
# Activate environment (Windows: .venv\Scripts\Activate.ps1; POSIX: source .venv/bin/activate)
python -m pip install -e ".[dev]"
python -m pytest
python -m logqa run
```

Public execution requires package download and therefore network access to PyPI. During creation in a restricted container, dependencies were preinstalled and the package was installed offline with `--no-build-isolation --no-deps`. Normal pip installation should work with internet access but has not been tested on the recruiter's machine.

## Artifacts

- `results/window_features.csv`: features plus previously assigned simulation labels.
- `results/detections.csv`: both predictions, the IF score, and hybrid decision.
- `results/metrics.csv`: full confusion counts, precision, recall and F1.
- `results/run_metadata.json`: input hashes, package versions, algorithm settings, synthetic counts.
- `figures/01_*`, `02_*`, `03_*`: data-derived figures regenerated by the CLI.
- `figures/00_pipeline_architecture.*`: conceptual diagram regenerated separately by `python scripts/generate_architecture.py` (not experimental data).

## Reproducibility cautions

Some scikit-learn releases can change floating point behavior or internal details. `pyproject.toml` lists supported version ranges; use the versions above if exact observed results matter. Any evaluation on new data must be described as a new experiment. Time-zone offsets are not present in the synthetic source logs, so timestamps are interpreted as naive, demonstration-local timestamps.
